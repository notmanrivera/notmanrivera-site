03 Diseño web UI/UX

Seis industrias, un mismo estándar

Diseño web no es una plantilla que se repite: cada industria resuelve problemas distintos, aunque el estándar visual y de usabilidad se mantenga. Una muestra del rango de proyectos.

Mi rol

Diseño y desarrollo de principio a fin, en trato directo con cada cliente: estructura, identidad visual, maquetación e implementación de los siete sitios.

Moser Café Kultur

2019 · Café con conciertos de jazz en vivo

Sitio y kit de redes sociales para un café que además funciona como foro de jazz en vivo — la identidad tenía que sostener las dos caras del negocio, cafetería de día y venue de noche.

Café Amadeus

2019 · Restaurante

Sitio responsive para un restaurante — el objetivo es simple pero exigente: que el menú y la ubicación se vean bien y se lean rápido, sin importar en qué pantalla llega el cliente.

Grupo Uno22

2020 · Holding de marcas

Sitio corporativo para un holding que agrupa varias marcas bajo un mismo paraguas — la jerarquía visual tiene que dejar claro qué es el grupo y qué es cada marca dentro de él.

Saxodia

2020 · Cuarteto de saxofones

Sitio y app para un cuarteto de saxofones — presencia digital para un acto musical, pensada para reservar fechas y mostrar repertorio.

V-Dental

2021 · Insumos dentales

Ecommerce y app para un distribuidor de insumos dentales — el proyecto con más alcance funcional del grupo: catálogo, carrito y checkout para compradores B2B, no solo un catálogo estático.

Viterbo 68

2023 · Bienes raíces

Sitio y app para una desarrolladora inmobiliaria — el reto de siempre en bienes raíces: que las fotos y planos de cada propiedad se vean bien y carguen rápido.

Incómodo

2023 · Estudio creativo

Portafolio web para un estudio creativo — aquí el sitio mismo es la pieza de exhibición, así que la barra de diseño es más alta: tiene que sostenerse como trabajo propio, no solo mostrar el de alguien más.
